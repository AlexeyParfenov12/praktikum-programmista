# Практикум программиста

Интерактивный курс на React + TypeScript + Vite. Работы №1–16 перенесены из предоставленных DOCX. Обязательные задания сохранены, дополнительные блоки удалены. №17–60 — планируемые темы, без кнопки завершения. Сервер и регистрация не нужны.

## Локальный запуск

1. Установите Node.js 22 LTS.
2. Откройте терминал в папке проекта.
3. Выполните `npm install`.
4. Выполните `npm run dev` и откройте указанный адрес.
5. Проверка типов: `npm run typecheck`.
6. Production-сборка: `npm run build`.
7. Проверка сборки: `npm run preview`. Откройте адрес из терминала.

## Публикация на GitHub Pages

1. Создайте на GitHub пустой репозиторий (без README), например `programmer-practice`.
2. В папке проекта выполните `git init`, затем `git add .`, `git commit -m "Initial course"`, `git branch -M main`.
3. Добавьте адрес своего репозитория: `git remote add origin https://github.com/USERNAME/REPOSITORY.git` и выполните `git push -u origin main`. Если origin уже связан с Sites, используйте отдельную чистую копию из ZIP или добавьте GitHub под другим именем.
4. В репозитории откройте Settings → Pages → Source → GitHub Actions.
5. Откройте Actions и дождитесь завершения GitHub Pages. При необходимости запустите workflow вручную через Run workflow.
6. Ссылка появится в Settings → Pages: `https://USERNAME.github.io/REPOSITORY/`.
7. Для обновления: измените файлы, выполните `git add .`, `git commit -m "Update course"` и `git push`. Actions заново соберёт сайт.

В `vite.config.ts` задан `base: './'`: пути к ресурсам относительные и работают в подпапке репозитория. При желании задайте `base: '/REPOSITORY/'` для конкретного репозитория. Навигация основана на URL hash (`#/lesson/1`); обновление страницы не требует перенаправления сервера.

Workflow уже включён в `.github/workflows/pages.yml`. Репозиторий: https://github.com/AlexeyParfenov12/praktikum-programmista. Workflow проверяет лекции и собирает сайт при каждом изменении main; публикация Pages выполняется для открытого репозитория после включения Pages в настройках. Это копия проекта для GitHub Pages. Данные размещения Sites в неё не включены.

## Учебные материалы

- `src/originals.json`: структурированное извлечение текста из 16 исходных DOCX, с таблицами. Исходные файлы пользователя не изменялись.
- `src/data.ts`: каталог, модули, словарь, удаление дополнительных блоков и совместимое с прежней версией разделение исходных материалов.
- `src/main.tsx`: обзор, каталог, справочник, прогресс, помощь и совместимость старых адресов.
- `src/ReadingLecture.tsx` и `src/reading-content.ts`: обычная лекция одной колонкой, исходный текст в прежнем порядке и скриншоты непосредственно после инструкций.
- `src/ReadingCode.tsx`: отдельные блоки C# с подсветкой и копированием.
- `src/task-help.ts`: подсказки и добровольные примеры кода к 41 самостоятельному заданию.
- `src/lecture-shots.ts`: точные места снимков в каждой лекции с проверкой единственного совпадения абзаца.
- `src/vs-shots.ts`: подписи настоящих снимков и пояснения к примерам.
- `src/screenshot-sizes.json`: реальные размеры JPEG, чтобы загрузка снимков не сдвигала текст. Обновление: node scripts/update-image-sizes.mjs.
- `src/Code.tsx`: подсветка, копирование и построчное объяснение C#.
- `src/Lecture.tsx`: интерактивность внутри урока — вопросы, снимки формы и раскрываемая пошаговая самопроверка.
- `src/lecture-data.ts`: понятия, вопросы, ключевые фрагменты кода и заранее подготовленные состояния разбора для каждой работы.
- `public/vs-real/`: 89 настоящих снимков установленной Visual Studio Community 2022 и запущенных .NET WinForms примеров для всех 16 работ. Старые рисованные схемы удалены из сайта.
- `src/style.css`: адаптивная светлая тема.

Чтобы изменить существующую работу, редактируйте её запись в `originals.json`. Сохраняйте id, обязательные формулировки, исходные данные и критерии. Проверяйте разделение этапов через `stageContent`. Для будущих работ добавляйте полноценный материал, затем изменяйте запись каталога на `ready: true` и добавляйте обработку содержания. Не отмечайте темы доступными до появления методички.

В таблицах используется маркер `@@TABLE:` с JSON-массивом строк, `@@SKIP` сохраняет позиции извлечённых абзацев. Эти маркеры отображаются компонентом Material как доступные HTML-таблицы, а не как текст. При редактировании №16 сверяйте её границы этапов, поскольку исходная структура контрольной отличается от обычных занятий.

## Чтение лекций и прогресс

Все 16 лекций идут одной колонкой: исходный текст, затем относящийся к нему настоящий снимок или блок C#. Нет карты действий, обязательного перехода по карточкам и боковых панелей. Скриншот можно открыть в полном размере. Материал отображается в исходном порядке без дублирования разделов №16.

К 41 самостоятельному заданию добавлены подсказки и пример кода, раскрываемый по желанию. Студент может решать самостоятельно или пользоваться примером. В конце обычных лекций есть добровольный пошаговый разбор ключевых фрагментов. C# выполняется в Visual Studio.

Прогресс хранится в localStorage praktikum-v1. Кнопка в конце помечает всю работу пройденной; прежние данные сохранены. Основной адрес — #/lesson/:id. Старые #/lesson/:id/:stage и #/work/:id/:step открывают ту же полную лекцию, без прежних панелей.

В пояснениях исправлены ошибки присваивания, сравнения, return, using и объявления метода. У примеров уточнено, что заменять и куда добавлять код; обязательные формулировки и исходные DOCX сохранены. При запрете копирования или сохранения прогресса отображается понятное сообщение.

89 настоящих кадров сняты в установленной Visual Studio Community 2022 (русский интерфейс, тёмная тема) и при запуске учебных .NET WinForms приложений. Снимки показывают конкретные приёмы; общие примеры подписаны отдельно. №14 демонстрирует переход из каталога №15; короткий пример №15 задаёт производителя в коде. Полные требования остаются в исходном задании.

Проверки: npm run build; node scripts/check-content.mjs; node scripts/check-lectures.mjs; node scripts/check-readings.mjs. Последняя проверяет порядок и полноту текста, наличие изображений и примеров ко всем самостоятельным заданиям, форматирование C# и отображение всех 16 лекций.

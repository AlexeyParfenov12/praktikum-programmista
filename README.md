# Практикум программиста

Статический учебный сайт на React + TypeScript + Vite для всей группы. Готовые лекции №1–16 перенесены из предоставленных DOCX: обязательные задания, исходные данные и критерии сохранены. №17–60 остаются планом курса.

Сайт опубликован на [GitHub Pages](https://alexeyparfenov12.github.io/praktikum-programmista/). Исходники находятся в [репозитории проекта](https://github.com/AlexeyParfenov12/praktikum-programmista).

## Лекции и навигация

Каждая лекция читается одной колонкой: текст, относящийся к нему настоящий скриншот Visual Studio или блок C#. Снимки открываются в полном размере, код можно копировать. В самостоятельных заданиях есть описание, подсказки и добровольный пример кода. В конце доступны пояснения к последовательности выполнения подготовленных примеров. Код запускается в Visual Studio, а не в браузере.

Общее меню закреплено сверху на всех страницах, включая лекции. Из него доступны обзор, практические работы, справочник и помощь. На небольших экранах ссылки открываются кнопкой «Меню». Из заголовка лекции можно перейти в справочник с фильтром этой работы.

Персональный прогресс и отметки о завершении удалены. Учётных записей, сохранения ответов и хранения прогресса в localStorage нет. Все студенты видят одни и те же материалы; сдачу и оценку преподаватель проверяет по проекту и отчёту. Текст поиска и выбранные фильтры — временное состояние страницы, а не данные студента.

## Справочник

Справочник — отдельный раздел с поиском по имени команды, функции, свойства, события, русскому объяснению и поисковым синонимам. Фильтры позволяют выбрать категорию, материал из доступных лекций или дополнительные темы, а также конкретную лекцию.

Статья содержит назначение, синтаксис, пример кода, важные пояснения и ссылку на первичную документацию. Если понятие встречается в готовых лекциях, рядом доступны ссылки на них. Пометка «Дополнительный материал» означает, что статья расширяет курс и пока не привязана к доступным лекциям. Темы будущих работ не считаются готовыми лекциями.

В базе 456 статей. Она включает C#, Windows Forms, Visual Studio, работу с файлами, SQL/PostgreSQL, Git и команды .NET. Помимо подготовленных статей, индекс дополняется именами компонентов и терминами из материалов курса. Примеры показываются как код и не выполняются сайтом.

## Локальный запуск

1. Установите Node.js 22 или совместимую более новую версию.
2. Откройте терминал в папке проекта.
3. Выполните `npm ci`.
4. Выполните `npm run dev` и откройте указанный адрес.
5. Проверка типов: `npm run typecheck`.
6. Сборка сайта: `npm run build`.
7. Проверка сборки: `npm run preview`. Откройте адрес из терминала.

## Публикация и обновление

GitHub Pages уже работает для репозитория `AlexeyParfenov12/praktikum-programmista`. Workflow `.github/workflows/pages.yml` запускается при изменениях ветки `main` и вручную из Actions. Он устанавливает зависимости, проверяет лекции, собирает сайт и публикует папку `dist`.

Для обновления внесите изменения, выполните проверки, создайте коммит и отправьте его в `main`. Результат публикации виден в Actions. Настройку Pages или новый репозиторий повторно создавать не нужно.

В `vite.config.ts` используется `base: './'`, поэтому ресурсы доступны в подпапке репозитория. Навигация основана на URL hash: `#/lesson/1`, `#/catalog`, `#/glossary`. Обновление страницы не требует серверных перенаправлений. Это самостоятельная копия проекта для GitHub Pages; данные размещения Sites в неё не включены.

## Основные файлы

- `src/main.tsx` — вход приложения.
- `src/Portal.tsx` — маршруты, обзор, каталог и помощь.
- `src/SiteNav.tsx`, `src/site-nav.css` — единое закреплённое меню и его мобильный вариант.
- `src/Handbook.tsx` — поиск, фильтры и чтение статей справочника.
- `src/handbook-types.ts` — общие типы справочных статей и индекса.
- `src/handbook-csharp.ts`, `src/handbook-winforms.ts`, `src/handbook-extra.ts` — подготовленные статьи по языку, интерфейсам и дополнительным технологиям.
- `src/handbook-index.ts` — общий индекс, связь статей с готовыми лекциями и дополнение терминами курса.
- `src/handbook-term-examples.ts` — примеры для определений из словарей лекций.
- `src/originals.json` — структурированное извлечение текста из 16 исходных DOCX, включая таблицы. Исходные файлы пользователя не изменялись.
- `src/data.ts` — каталог, модули и обработка исходных материалов.
- `src/ReadingLecture.tsx`, `src/reading-content.ts` — полная лекция в исходном порядке, со скриншотами после соответствующих инструкций.
- `src/ReadingCode.tsx` — блоки C# с подсветкой, а также SQL, команды терминала и текстовые примеры с копированием.
- `src/task-help.ts` — подсказки и добровольные примеры к самостоятельным заданиям.
- `src/lecture-shots.ts` — точные места снимков с проверкой единственного совпадения абзаца.
- `src/vs-shots.ts` — подписи настоящих снимков и пояснения к примерам.
- `src/screenshot-sizes.json` — размеры JPEG для резервирования места до загрузки. Обновление: `node scripts/update-image-sizes.mjs`.
- `public/vs-real/` — настоящие снимки установленной Visual Studio Community 2022 и запущенных .NET WinForms приложений для всех 16 работ.
- `src/style.css` — общие стили сайта.

## Редактирование материалов

Чтобы изменить существующую работу, редактируйте её запись в `originals.json`. Сохраняйте id, обязательные формулировки, исходные данные и критерии. Материал показывается в исходном порядке без дублирования разделов №16. При добавлении новой лекции сначала подготовьте полный материал и только затем меняйте запись каталога на `ready: true`.

В таблицах используется маркер `@@TABLE:` с JSON-массивом строк; `@@SKIP` сохраняет позиции извлечённых абзацев. На сайте эти маркеры преобразуются в HTML-таблицы и не показываются студенту.

Статьи справочника добавляйте в соответствующий `handbook-*.ts` с уникальным id, синтаксисом, полезным примером, пояснениями и ссылкой на официальную документацию. `lectureTokens` задаёт выражения для проверки присутствия в материалах. Не присваивайте статье связь с лекцией только потому, что тема есть в плане курса. Для одноимённых конструкций разных языков используйте точные токены, исключающие случайное совпадение.

Настоящие снимки показывают конкретные приёмы; общие примеры подписаны отдельно. Полные требования сохраняются в тексте исходного задания. Копирование кода сообщает об отказе доступа к буферу обмена.

## Проверки

- `npm run typecheck` — типы TypeScript.
- `npm run build` — готовая сборка сайта.
- `node scripts/check-content.mjs` — обязательное содержание работ.
- `node scripts/check-lectures.mjs` — структура и материалы лекций.
- `node scripts/check-readings.mjs` — полнота и порядок текста, наличие изображений и примеров, форматирование C# и отображение всех 16 лекций.
- `node scripts/check-handbook.mjs` — целостность справочника, поиск и фильтры, связи с лекциями, меню и отсутствие личного прогресса.

При изменении навигации и справочника также проверьте переходы с длинной лекции, мобильное меню, поиск, сочетания фильтров и ссылки между статьями и лекциями.

## Проекты для студентов

Раздел `#/downloads` и ссылки в заголовках лекций предлагают 16 стартовых проектов (к началу занятия 1–16) и исходный демонстрационный проект со скриншотов. ZIP содержат решение, C#, конструкторы и инструкцию. Примеры предыдущих занятий подготовлены; самостоятельные задания и личные изменения студентов не включены. Расположение элементов восстановительных баз упрощено.

`node scripts/build-project-downloads.mjs [папка-для-сборки]` заново создаёт стартовые базы из основных примеров методичек, компилирует каждую и упаковывает только исходники. Выполняется на Windows с установленным .NET SDK и PowerShell. `public/downloads/screenshot-examples.zip` содержит сохранённый демонстрационный проект с меню выбора 16 форм. Проверка архивов: `python scripts/check-downloads.py`.

# Архитектура платформы

React + TypeScript + Vite, статический сайт с hash-навигацией. №1–16 — готовые лекции, №17–60 — план. Каталог и прежний прогресс сохраняются.

ReadingLecture показывает всю лекцию одной колонкой. reading-content.ts использует documents.paragraphs в исходном порядке: абзацы не переставляются и не дублируются. После нужной инструкции добавляется настоящий скриншот из public/vs-real. lecture-shots.ts задаёт точные префиксы абзацев; при отсутствии или неоднозначности привязки проверка завершается ошибкой. Размеры из screenshot-sizes.json резервируют место изображения ещё до загрузки. Исходный код отображается ReadingCode с подсветкой C# и копированием.

Самостоятельные задания сохраняют исходные формулировки. task-help.ts добавляет подсказки и добровольные примеры к 41 заданию. Это обычный текст и раскрываемый по желанию код. Отдельных рабочих панелей, тренажёров и обязательных шагов нет. В конце лекций доступны ключевые примеры и объяснение последовательности выполнения.

Основной маршрут #/lesson/:id. Старые адреса #/lesson/:id/:stage и #/work/:id/:step открывают полную лекцию того же номера. localStorage praktikum-v1 хранит старые отметки; новая кнопка отмечает всю работу пройденной. Серверной оценки и синхронизации нет.

Проверки: TypeScript, production-сборка, обязательные формулировки, удаление дополнительных заданий, исходный порядок всех абзацев, настоящие JPEG, примеры для самостоятельных и серверное отображение всех 16 лекций.

Копирование C# обрабатывает отсутствие API и отказ доступа. При запрете localStorage сообщение показано в самой лекции у отметки прогресса. Нормализация точных пояснений в data.ts исправляет ошибки теории без изменения обязательных заданий и originals.json.

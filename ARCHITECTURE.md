# Архитектура платформы

React + TypeScript + Vite, статический сайт с hash-навигацией. Готовы лекции №1–16; №17–60 представлены как план. Production-размещение — GitHub Pages: https://alexeyparfenov12.github.io/praktikum-programmista/.

## Маршруты и общее меню

`main.tsx` подключает приложение, `Portal.tsx` выбирает страницу по hash-маршруту. Основной адрес лекции — `#/lesson/:id`. Старые `#/lesson/:id/:stage` и `#/work/:id/:step` открывают ту же полную лекцию. Старые маршруты прогресса и тренажёров ведут в каталог.

`SiteNav.tsx` и `site-nav.css` задают единое закреплённое меню обзора, практических, справочника и помощи. Оно используется и на общих страницах, и в `ReadingLecture`, поэтому навигация доступна при чтении и прокрутке любой лекции. На небольших экранах меню раскрывается кнопкой; переход и Escape закрывают его.

## Отсутствие личного состояния

Учётных записей, личного прогресса, отметок выполнения и сохранённых ответов нет. Приложение не использует localStorage для данных студента. Поисковая строка, раскрытие меню и выбранные фильтры хранятся только во временном состоянии React; маршрут позволяет открыть нужный материал по ссылке.

Материалы общие для всех студентов. Сайт не оценивает выполнение: преподаватель проверяет проект и отчёт. Примеры C#, SQL и командной строки отображаются как учебный код и не исполняются приложением.

## Чтение лекций

`ReadingLecture.tsx` показывает лекцию одной колонкой. `reading-content.ts` использует `documents.paragraphs` в исходном порядке: абзацы не переставляются и не дублируются. После соответствующей инструкции добавляется настоящий скриншот из `public/vs-real`.

`lecture-shots.ts` задаёт точные префиксы абзацев. При отсутствии или неоднозначности привязки проверка завершается ошибкой. Размеры из `screenshot-sizes.json` резервируют место изображения до загрузки. `ReadingCode.tsx` показывает C# с подсветкой и копированием; отказ доступа к буферу обмена обрабатывается сообщением.

Самостоятельные задания сохраняют исходные формулировки. `task-help.ts` добавляет подсказки и добровольные примеры. Материал остаётся обычным текстом с раскрываемым по желанию кодом, без отдельных рабочих панелей и обязательной последовательности действий. В конце лекций доступны ключевые примеры с пояснением порядка выполнения.

Нормализация точных пояснений в `data.ts` исправляет ошибки теории без изменения обязательных заданий и исходного `originals.json`.

## Справочник

`Handbook.tsx` — отдельная страница справочника. Она предоставляет поиск, фильтры по категории, присутствию в лекциях и конкретной работе, а также чтение статьи с синтаксисом, примером и пояснениями. Статьи с совпадениями в готовых лекциях показывают ссылки на эти лекции; остальные помечены как дополнительный материал. Из лекции можно открыть справочник с фильтром соответствующей работы.

Содержимое разделено на модули:

- `handbook-types.ts` — `HandbookEntry` и индексированная статья с `lectureIds`.
- `handbook-csharp.ts` — язык C#, типы и стандартные API.
- `handbook-winforms.ts` — Windows Forms, свойства, события и работа в Visual Studio.
- `handbook-extra.ts` — SQL/PostgreSQL, базы данных, Git и команды .NET.
- `handbook-index.ts` — объединение статей, определение связей с доступными лекциями и дополнение именами компонентов и терминами из курса.

Каждая подготовленная статья имеет устойчивый уникальный id, название, категорию, вид, описание, синтаксис, пример, примечания и URL первичной документации. Поисковые синонимы помогают найти статью, а `lectureTokens` уточняет, по каким выражениям устанавливать присутствие в материале. Указание языка кода позволяет корректно оформлять C#, SQL, команды и обычный текст.

Связи вычисляются по содержимому готовых лекций. План будущих тем не даёт статье статус «есть в лекции». Неоднозначные слова и конструкции разных языков требуют точных токенов, чтобы SQL CASE или DEFAULT не совпали с одноимённым синтаксисом C#.

Поисковый индекс и фильтрация работают локально в браузере. Сервер, аккаунты и сохранение фильтров в localStorage не требуются.

## Проверки и публикация

Проверки охватывают TypeScript, production-сборку, обязательные формулировки, исходный порядок абзацев, настоящие JPEG, примеры для самостоятельных заданий и отображение всех 16 лекций. Навигацию и справочник дополнительно проверяют на переходах из лекции, мобильном меню, поиске, сочетаниях фильтров и обратных ссылках.

Workflow `.github/workflows/pages.yml` использует Node.js 22, выполняет проверки содержания и сборку, затем публикует `dist` на GitHub Pages при обновлении `main`. Относительный `base: './'` сохраняет работоспособность ресурсов в подпапке репозитория. Hash-маршруты не требуют серверных правил перенаправления.
